# Olympus 2249 한글 패치 (비공식 팬 번역) — 검수 베타

*Olympus 2249*(Steam)의 비공식 한국어 번역입니다. 게임 내 언어 목록에서 **중국어(中文（机翻）) 자리가 한국어로 바뀌는** 방식이며, English 원문은 그대로 유지됩니다.

- 게임 버전: 0.9.8.0-HF2 기준
- 번역 범위: 51개 표, 7,553개 항목 (대사 3,288 / 퀘스트 1,473 / 주변·전투 대사 321 / UI·아이템·인물·사전·도움말 2,471)
- 상태: **검수 베타(Beta 004)** — 세계관과 인물별 말투를 반영한 1차 번역입니다. 전체 플레이 검수를 마친 완성본이 아니므로 어색한 문장·오역은 Issues나 검수용 엑셀로 알려 주세요.
- Beta 004는 게임 0.9.8.0-HF2 업데이트 대응판입니다(바뀐 점은 아래 [변경 내역](#변경-내역) 참고). 패치 파일 재추출·원문 대조·설치기 시험을 마쳤고, **HF2 게임에서 설치와 한글 출력이 정상인 것을 확인했습니다.**

## 설치 방법 (Windows)
1. 게임을 완전히 종료합니다. 이전에 설치한 KR-AOS 패치(출력 시험 001, 베타 002, 베타 003 등)가 있다면 해당 패키지의 `remove.bat`로 먼저 제거합니다. 이전 버전과 함께 설치할 수 없으며, Beta 003이 남아 있으면 설치기가 안내 후 중단합니다.
2. [Releases](../../releases)에서 `Olympus2249_KR_Review_Beta004.zip`을 받아 **모두 풀고** `install.bat`을 실행합니다. 게임 폴더를 찾지 못하면 경로를 입력하라고 안내합니다.
3. 게임의 언어 설정에서 **중국어 中文（机翻）**을 고릅니다. 적용 후에는 **한국어 (KR-AOS)**로 표시됩니다.
4. 영어 원문과 비교하려면 언어를 English로 바꿉니다.

제거하려면 같은 폴더의 `remove.bat`를 실행합니다.

## 설치기가 하는 일
- 게임 원본 PAK(`O2Project-Windows.pak`)의 버전·크기·SHA256을 확인한 뒤 별도의 패치 PAK 하나를 추가합니다. **원본 PAK와 세이브 파일은 수정하지 않습니다.**
- 게임 업데이트로 기준 버전이 달라졌으면 설치를 중단합니다. 업데이트 후에는 새 패치를 기다려 주세요. (HF2 업데이트로 원본 PAK가 바뀌어 Beta 003 설치기는 중단되며, HF2에는 Beta 004를 사용합니다.)
- 문제가 생기면 같은 폴더의 `installation-log.txt`를 확인하세요.

## 알려진 문제
- 특성 화면의 Lvl / Combat / Generic / Non-combat 영어 잔여
- 일부 전투 로그의 `None` 이름 표시
- 일부 기술 설명 아래쪽 잘림
- 공통 메뉴(Credits / Roadmap / Legal Information)와 이미지 속 영어
- 대화창 띄어쓰기가 빠져 보이는 표시 문제 (번역표에는 공백이 들어 있으며 원인 조사 중)

위 문제는 Beta 004에서 수정하지 않았습니다. 자세한 내용은 [docs/KNOWN_ISSUES.txt](docs/KNOWN_ISSUES.txt)를 확인해 주세요.

## 검수 참여
Releases의 ZIP에 영어 원문·한국어 번역·문장 ID·피드백 칸이 있는 검수용 엑셀이 들어 있습니다. 노란 칸에 문제 유형과 수정 의견을 적고, 문장 ID·발생 장면·스크린샷과 함께 알려 주세요. 원문과 기존 번역 칸은 그대로 두어 주세요. ID가 없는 UI 문제는 화면과 재현 상황을 알려 주시면 됩니다. Beta 004 엑셀에는 HF2 신규·변경 17개 항목이 "검수 메모" 칸에 표시되어 있습니다.

## 저장소 구성
| 경로 | 내용 |
|---|---|
| `translations/ko.tsv` | 번역표 (문장 ID, 분류, 한국어, 상태) |
| `docs/KNOWN_ISSUES.txt` | 알려진 문제 |
| `LICENSE-NotoSansCJK-OFL.txt` | 글꼴 라이선스(SIL OFL 1.1) |
| `NOTICE.md` | 출처·저작권 고지 |

번역표에는 영어 원문이 들어 있지 않고 ID와 한국어만 있습니다. 탭으로 나뉜 CSV 방식(따옴표 처리) 파일이므로 단순 split 대신 TSV/CSV 파서나 엑셀로 열어 주세요. `status`가 `preserved`인 항목(566개)은 말줄임·변수·숫자·약어·내부 식별자 등 의도적으로 원문을 유지한 항목이며, 미번역 대사를 뜻하지 않습니다.

## 번역 방침
- 서술·행동 지문은 평서체(~다), 불필요한 "당신"은 피합니다. 기본 UI·안내는 간결한 존댓말입니다.
- 인물 성격과 화자·청자 관계, 상황에 맞춰 말투를 정하고 파일 이름만으로 화자를 일괄 지정하지 않습니다.
- 욕설과 유머는 원문 수위를 유지합니다. 게임 태그·변수(`{ActS}`, `{ActE}`, `[lb]` 등)와 내부 키는 그대로 둡니다.
- 일부 고유명사(올림푸스, 래디우스, 수집자 등)는 잠정 표기이며 검수 중 바뀔 수 있습니다.
